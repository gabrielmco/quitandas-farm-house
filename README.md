# Quitandas Farm House 🍲🥖

> **Web App Delivery de Doces e Caldos Artesanais em Lima Duarte - MG.**

Projeto web responsivo de alta performance (100% SEO, Acessibilidade e Melhores Práticas), com carrinho de compras interativo, checkout automatizado com envio de pedidos via WhatsApp, painel gestor administrativo completo com **DRE Financeiro**, **BI Analytics**, **Curva ABC**, **Rastreamento de Visitantes & Clientes** e **Auto Keep-Alive 24/7 para Supabase**.

## 🚀 Tecnologias Utilizadas
- **Core**: HTML5, CSS3 (Vanilla CSS com Glassmorphism), JavaScript ES6+ Modules
- **Bundler & Build Tool**: Vite 6
- **Database & Auth**: Supabase (@supabase/supabase-js)
- **Animações & Ícones**: Anime.js, Phosphor Icons
- **Automação & Deployment**: Vercel Serverless & Cron Jobs, GitHub Actions Keep-Alive 24/7

## ⚡ Comandos para Desenvolvimento
```bash
# Instalar dependências
npm install

# Rodar servidor local de desenvolvimento
npm run dev

# Gerar bundle otimizado de produção
npm run build

# Preview do build de produção
npm run preview
```

## 🛡️ Mantimento 24/7 do Supabase
O projeto possui integração automatizada nativa via **Vercel Cron Jobs** e **GitHub Actions** em `.github/workflows/supabase-keep-alive.yml` que dispara pings a cada 3 dias para garantir que o banco gratuito do Supabase permaneça ativo sem interrupções por inatividade.
